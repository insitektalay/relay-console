that no successful test has been recorded here yet.

## Get help or report a result

If a connection fails, [open a GitHub issue](https://github.com/insitektalay/relay-console/issues/new)
and include:

- the application name;
- whether you used the macOS, web, or iPhone/iPad client;
- the step that failed; and
- the exact error message, with credentials and personal data removed.

Never post API keys, access tokens, passwords, private messages, customer data,
or screenshots that contain sensitive information.
