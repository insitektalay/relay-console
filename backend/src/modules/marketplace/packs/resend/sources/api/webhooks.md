Resend webhooks can report email.sent, email.delivered, email.delivery_delayed, email.complained, email.bounced, email.opened, and email.clicked where enabled. Webhook secrets and endpoint changes require approval.

Webhook/event endpoint creation, event subscription changes, callback URL changes, signing-secret rotation, and deletion require approval and audit.
