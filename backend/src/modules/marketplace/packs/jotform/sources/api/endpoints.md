# Jotform MCP Tools

- `form_list`: list authorized forms.
- `get_submissions`: read submissions accepted by its live schema.
- `create_form`: create a form using the exact live MCP schema.
- `edit_form`: edit an identified form using the exact live MCP schema.
- `create_submission`: create a submission using the exact live MCP schema.

Do not translate these into Jotform REST endpoints.
