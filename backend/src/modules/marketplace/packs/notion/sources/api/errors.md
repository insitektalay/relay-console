Common Notion failures include unauthorized, restricted_resource, object_not_found, validation_error, rate_limited, conflict_error, and service_unavailable. restricted_resource/object_not_found often means the integration has not been granted access.

On authentication, authorization, validation, conflict, quota, throttling, provider outage, or partial-write failures: stop, summarize the safe provider error, preserve object ids, and do not retry side-effecting writes blindly.
