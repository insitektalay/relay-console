# Workflow: Create or Update an Issue

1. Identify the repository.
2. Search for an existing issue or PR that already tracks the work.
3. If one exists, comment or update instead of duplicating.
4. If creating a new issue:
   - write a clear title;
   - include evidence, impact, and next action;
   - apply labels only when they are known and appropriate.
5. If the issue would expose secrets, internal security detail, or vulnerability-sensitive information, stop and escalate.
