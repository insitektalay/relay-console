# Workflow: Merge a Pull Request

1. Confirm explicit human approval exists in the ClawChat approval flow.
2. Confirm required checks, reviews, and branch policies are satisfied.
3. Confirm the PR is the correct one and still targets the intended base branch.
4. Merge using the repository's expected method only after approval.
5. Report the merge result with repository, PR number, branch, and merge method.

If any branch protection or ruleset blocks the merge, stop and report that state. Do not work around it.
