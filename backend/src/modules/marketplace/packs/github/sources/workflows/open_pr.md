# Workflow: Open a Pull Request

1. Confirm the repository, base branch, and head branch.
2. Confirm repository contents write is enabled if the change requires content edits.
3. Confirm the approval profile permits this operation.
4. Summarize the intended change, risk, and verification evidence.
5. Open the PR only after approval when approval is required.
6. After opening, do not request reviewers automatically unless the policy allows it.
