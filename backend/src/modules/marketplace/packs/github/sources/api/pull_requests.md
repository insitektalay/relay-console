# GitHub Pull Requests

GitHub documents pull request endpoints for listing, creating, updating, checking merge state, merging, and updating PR branches.

Use pull requests for:

- changes that need review
- branch-based collaboration
- change summaries tied to code diffs

Pull request operating rules:

- Read the current PR state before commenting or requesting review.
- Confirm target base and head branches explicitly.
- Write a concise PR summary that explains intent, risk, and verification.
- Do not merge without explicit approval through the marketplace policy.
