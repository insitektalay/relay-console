Database webhooks can emit INSERT, UPDATE, DELETE events for configured tables. Edge functions and auth hooks may be part of app architecture. Webhook endpoints, secrets, and trigger configuration require approval.

Webhook/event endpoint creation, event subscription changes, callback URL changes, signing-secret rotation, and deletion require approval and audit.
