- Contacts: people records, emails, lifecycle data, owner, properties, company/deal/ticket/activity associations.
- Companies: account records, domains, firmographics, owners, child/parent relationships, contact/deal/ticket associations.
- Deals: sales opportunities tracked through pipelines and stages; amount, close date, owner, associations, products where present.
- Tickets: support records tracked through ticket pipelines/statuses and associated contacts/companies.
- Properties: internal names and options define valid payload fields. Always resolve before writes.
- Associations: relationships between object records, including labeled association types in newer APIs.
- Owners: HubSpot users used for assignment/routing.
- Lists: segmentation surfaces; list-wide exports or mutations require approval.
- Activities: notes, tasks, calls, emails, meetings, and related engagement-like objects that can attach to CRM records.
