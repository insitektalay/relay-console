HubSpot webhooks can notify integrations about CRM object changes such as contact, company, deal, ticket, and property events when configured. Workflow webhook actions can also send data to external systems.

Creating, deleting, or modifying webhook subscriptions, callback URLs, secrets, event types, workflow webhook actions, or retry handling requires approval. Verify signatures/secrets without exposing secret values.
