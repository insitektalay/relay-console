HubSpot's CRM API models records as objects with properties and associations. Core CRM/support objects for this pack are contacts, companies, deals, tickets, owners, pipelines, lists, and activity objects such as notes, tasks, calls, emails, and meetings.

Use CRM v3 objects for record CRUD and batch operations, CRM search for filtered reads, properties endpoints for schema, pipelines endpoints for stage/status validation, owners endpoints for assignment, and association APIs for relationships.

Official docs:

- https://developers.hubspot.com/docs/api/crm/understanding-the-crm
- https://developers.hubspot.com/docs/api/crm/search
- https://developers.hubspot.com/docs/api/crm/contacts
