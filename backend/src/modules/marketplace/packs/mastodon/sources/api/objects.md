# Mastodon Objects

Accounts, statuses, timelines, notifications, media attachments, scheduled statuses, favourites, boosts/reblogs, bookmarks, reports, instance rules, federation-visible URLs.

Write approvals must use provider-native identifiers rather than display names alone. Examples for this pack include Instance hostnames, account IDs, status IDs, media attachment IDs, notification IDs, report IDs, and Idempotency-Key values.
