# Mastodon Escalation

Escalate when:
- The target account/object cannot be proven.
- The requested action could publish, delete, hide, message, follow, react, or moderate content.
- Permissions, product access, app review, access tier, or rate limits block the request.
- The user asks for bulk engagement, spam, impersonation, policy bypass, scraping/private-data export, or unsafe admin/moderation.

Ask for the native identifier, exact payload, visibility/privacy setting, and explicit approval before proceeding.
