Official docs: https://pipedrive.readme.io/docs/guide-for-webhooks

Pipedrive webhooks can fire for object/action combinations such as added, updated, or deleted deals, persons, organizations, activities, products, pipelines, and stages. Deal stage changes are deal update events, not stage events.

Creating, modifying, or deleting webhooks, callback URLs, secrets, event filters, or application webhook configuration requires approval.
