Pipedrive is a sales CRM API with core entities for leads, deals, persons, organizations, activities, notes, products, users, pipelines, stages, filters, fields, files, and webhooks. Persons and organizations are contacts; deals and leads must be linked to a person or organization.

Prefer optimized current endpoints where available and use webhooks instead of polling for state changes.
