Pipedrive supports API token authentication and OAuth 2.0. API tokens are tied to a specific user and company and can access that user's data. OAuth apps authorize requests with access/refresh tokens for the installed company.

Store API tokens, OAuth tokens, client secrets, and webhook secrets only in ClawChat. Confirm company domain and auth type before requests. Never request or print raw tokens.
