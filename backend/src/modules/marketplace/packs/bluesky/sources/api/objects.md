# Bluesky Objects

DIDs, handles, PDS repositories, repo records, app.bsky.feed.post records, strong refs with uri/cid, facets for mentions/links/tags, embeds/images/blobs, feeds, profiles, labels, moderation reports.

Write approvals must use provider-native identifiers rather than display names alone. Examples for this pack include DIDs, handles, PDS hosts, AT URIs, CIDs, rkeys, blob refs, collection names such as app.bsky.feed.post, and moderation label values.
