Twilio status callbacks and product webhooks report message/call lifecycle states such as queued, sent, delivered, undelivered, failed, and inbound messages. Validate signatures where runtime supports it and treat callback URLs/secrets as sensitive.

Webhook/event endpoint creation, event subscription changes, callback URL changes, signing-secret rotation, and deletion require approval and audit.
