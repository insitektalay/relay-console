Salesforce REST API exposes versioned resources under `/services/data/vXX.X`. This pack focuses on sObjects, describes, SOQL query, SOSL search, Composite APIs, API usage headers, Platform Events, and Change Data Capture.

Core CRM/support objects: Account, Contact, Lead, Opportunity, Case, Task, Event, User, Group/Queue, and allowed custom objects.
