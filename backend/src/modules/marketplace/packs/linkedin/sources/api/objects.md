# LinkedIn Objects

Person URNs, organization URNs, posts, commentary, lifecycleState, visibility, media assets, social actions, comments, likes, analytics where product access allows.

Write approvals must use provider-native identifiers rather than display names alone. Examples for this pack include urn:li:person IDs, urn:li:organization IDs, post URNs, comment URNs, and media asset URNs.
