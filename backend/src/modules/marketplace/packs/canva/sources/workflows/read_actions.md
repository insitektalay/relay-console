## Read Workflow

1. Confirm connection, scope and resource boundary.
2. Resolve target IDs from official endpoints.
3. Fetch only fields/items needed for the user request.
4. Summarize state without exposing secrets or unnecessary personal/private content.

## Good Read Requests

- Find Canva designs updated this week and summarize names, owners and export readiness.
- List assets in the campaign folder and identify missing brand-approved images.
- Draft a reply to the designer comment thread without posting it.
