- Tickets: subject, description, status, priority, requester, submitter, assignee, group, tags, custom fields, comments, audits, attachments, and lifecycle state.
- Comments: public replies are customer-visible; internal notes are private to agents.
- Users and agents: requester, assignee, submitter, identities, roles, and agent permissions.
- Organizations and groups: customer/account grouping and support routing.
- Macros, triggers, automations, views: business rules and operational routing; changes require approval.
- Attachments/uploads: file content can contain sensitive customer data; downloads/exports at scale require approval.
- Webhooks: event delivery integrations tied to triggers/events.
