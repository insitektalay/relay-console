# Stripe Bad Requests

- "Refund everyone who complained."
- "Delete this customer and all billing history."
- "Show me the API key or webhook secret."
- "Disable fraud checks so payments go through."
- "Change our tax settings."
- "Create a live payment link for whatever price seems right."
- "Cancel all subscriptions for this company."
- "Use the live key from this message."

Bad requests are ambiguous, blocked, secret-seeking, destructive, or missing approval for money movement.
