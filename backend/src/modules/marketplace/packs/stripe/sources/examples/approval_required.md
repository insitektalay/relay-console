# Stripe Approval Required Examples

- Send invoice `in_...` to the customer.
- Finalize a draft invoice.
- Pay an invoice.
- Void an invoice.
- Mark an invoice uncollectible.
- Create a live payment link.
- Refund a payment.
- Cancel or update a subscription.
- Update customer billing settings.
- Create or update a product or price.
- Create, update, disable, or delete a webhook endpoint.

Approval must include environment, object IDs, amount/currency when relevant, expected result, and business reason.
