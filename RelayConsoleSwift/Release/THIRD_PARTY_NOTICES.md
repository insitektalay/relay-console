## User-Managed Harnesses

Relay Console interoperates with user-installed Hermes Agent and OpenClaw
runtimes but does not distribute or install them. Their licenses and dependency
notices remain with the user's installations. The signed release packet records
the runtime versions tested against
`Sources/RelayConsoleCore/Resources/harness-compatibility.json`.
