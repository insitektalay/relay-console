# Relay Console 0.1.1 public alpha

This is the first installable public-alpha release of the native Relay Console
app for macOS.

## Included

- First-launch setup for local or self-hosted Railway connections.
- Automatic discovery of standard Hermes Agent and OpenClaw installations,
  with a guided manual-location fallback.
- Native connection, agent, chat, Marketplace, operations, and settings
  surfaces.
- Optional, consent-gated PostHog product analytics and Sentry crash reporting.
- Secure Sparkle 2 update support for subsequent signed releases.

## Before using this alpha

Relay Console remains an early technical alpha. You provide and operate your
own compatible Hermes Agent or OpenClaw runtime and, where required, your own
Railway deployment. Windows is not supported yet.
