## Local Relay Console capability dimensions observed this run

These dimensions are grounded in local files inspected on 2026-06-28:

- macOS Swift app/package and test harnesses: `Package.swift` defines macOS 14+, `Relay Console`, `RelayMarketplaceToolBridge`, service/model/shell tests, event replay, visual evidence, capture, snapshot, and accessibility harness targets.
- Core service graph: `Sources/RelayConsoleCore/RelayConsoleServices.swift` wires local data/chat/agent/app/provider/runtime/security/artifact services, starts the marketplace runtime broker when configured, and registers Hermes/OpenClaw runtime adapters.
- Provider action integration/credential pattern: `Sources/RelayConsoleCore/ProviderConnectionService.swift`; Gmail/X/LinkedIn adapter services; marketplace policy compiler, wrapper tools, broker, and approval inbox services in `RelayConsoleServices`.
- Local runtime operations: `RuntimeBridgeRegistry`, `HermesAgentAdapter`, `OpenClawAdapter`, `HarnessInstallManager`, `RuntimeWorkspaceService`, `RuntimeDashboardService`, `RuntimeRecoveryService`, and `MarketplaceRuntimeToolBridgeService`; `Models.swift` also defines runtime types for `hermes`, `openclaw`, `claude_code`, and `codex_cli`.
- Marketplace runtime mounting: `Sources/RelayConsoleCore/MarketplaceRuntimeMountService.swift` filters active marketplace installs by assigned agent/runtime format, compiles wrapper tool surfaces, and reports tool counts/redaction status.
- Cron/autonomous operation: `Sources/RelayConsoleCore/HermesCronSchedulerService.swift` manages launchd installation/status for a Hermes profile background scheduler.
- Safety/approvals/audit: `MarketplaceProviderActionApprovalService`, `MarketplaceProviderActionApprovalInboxService`, `PermissionPolicyService`, `AuditSecurityService`, and `RuntimeActionService` blockers/dry-runs.
- Scope guard: `RuntimeActionService.hostControlExclusionReason` states Mission Control host-control, local app process control, and local app command execution are excluded from Swift scope, which matters when comparing Relay Console with OS/computer-control products like Raycast and Claude computer use.
- Evidence/replay/testing: event replay, visual evidence, accessibility capture, visual snapshot, component baseline, and service test targets in `Package.swift` and `Tests/`.
