## Where it differs

- Cursor is an AI-first coding environment; Relay Console local code is not a code editor and is grounded as a macOS operations console for chat/workspaces, agents, provider actions, runtime harnesses, approvals, artifacts, and evidence.
- Cursor's agents operate over codebases and developer tasks; Relay Console code integrates Hermes/OpenClaw runtimes and provider-action adapters such as Gmail/X/LinkedIn for broader agent operations.
- Cursor's pricing and packaging are mature/public; Relay Console's local codebase evidence shows product systems but not public packaging/pricing in the inspected files.
