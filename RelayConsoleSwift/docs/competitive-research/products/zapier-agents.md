# Zapier Agents / Zapier AI

## Summary

Zapier is a cloud automation platform now positioning AI as an operations layer over its app-integration network. Zapier's AI page describes a no-code automation platform across 9,000+ apps and lists Zaps, Tables, Forms, Canvas, Agents, Chatbots, app integrations, AI automation, security, Zapier MCP, SDK beta, Functions beta, and Lead Router: https://zapier.com/ai. Zapier Agents is a direct adjacent comparable for users who want AI teammates that can perform work across SaaS tools.

## Jobs/use cases

- Build no-code automations across SaaS apps; Zapier says its platform connects 9,000+ apps: https://zapier.com/ai.
- Create AI assistants/teammates that use company knowledge and do work across apps "on command and while you sleep": https://zapier.com/agents.
- Use AI orchestration, checks for sensitive data/unsafe inputs, and switch models without rebuilding workflows, as described on the Zapier AI page: https://zapier.com/ai.
- Connect external AI/chat/coding surfaces to apps through Zapier MCP or SDK/Functions beta, according to Zapier's AI page navigation: https://zapier.com/ai.

## Feature overlap with Relay Console

- Provider/action integrations: Zapier's strongest overlap is its large app-connection network, while Relay Console code has provider connections, Gmail/X/LinkedIn adapters, marketplace provider policies, wrapper tools, and a broker.
- Autonomous/agentic work: Zapier Agents overlaps with Relay Console's Hermes cron scheduler and runtime dispatch/autonomous-agent direction.
- Safety/governance: Zapier mentions built-in checks for sensitive data and unsafe inputs; Relay Console local code has approval inboxes, permission policies, audit security, dry-runs/blockers, and redaction-status fields.
- Tool bridge: Zapier MCP is strategically comparable to Relay Console's `RelayMarketplaceToolBridge` and runtime-mounted wrapper tools, although implementation and deployment models differ.

## Where it differs

- Zapier is a cloud SaaS automation and integration network; Relay Console code is a local macOS Swift app with local data services, runtime adapters, and same-machine runtime harness management.
- Zapier's public value proposition is breadth of app integrations and no-code workflow/agent building; Relay Console's differentiator is local runtime operations with approval/evidence artifacts around agent actions.
- Zapier automations generally run in Zapier's hosted platform; Relay Console has a launchd-backed Hermes cron scheduler and local runtime workspace services.
